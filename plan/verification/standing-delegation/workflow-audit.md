# Controlled workflow audit

The only new workflow is `.github/workflows/package-checks.yml` in the verified platform repository. It responds to PRs targeting `ambisgis/main` and pushes to that branch, has an explicit 10-minute timeout, one job, cancellation of superseded runs, and `permissions: {}`. No `pull_request_target`, secret, credential helper, cache restore, action dependency, artifact publication, deployment or merge step exists. Public Git fetch uses the fixed owned repository and validates the exact event commit before testing. Fork submissions whose objects are unavailable from the owned remote fail rather than changing remote URLs. Outside PRs remain ineligible under the separate merge gate.

The job uses Ubuntu 24.04 and explicitly refuses a Python version other than 3.12. It installs only binary validation tooling under `--require-hashes`; original wheel names/versions/hashes/licenses are recorded in `ci-inputs.json` and bytes are retained on the trusted runner. A real fresh Python 3.12 offline installation exposed a missing conditional typing_extensions input; the completed lock was installed and the full package/schema commands passed. This is development-tooling custody, not the product build-input closure or release SBOM.

Independent review must cover this workflow and the previous acceptance requirements before first push. The final reviewed source runs the full package suite and requires all four schemas. Successful live check identity is captured before it becomes required. Narrow settings changes are recorded separately after that observation. Source-fork Actions remain disabled; no donor workflow is enabled. This workflow does not test or certify GIS product journeys.

The native goal runtime is active in the recorded thread. Runtime tests exercise actual foreground processes, crash recovery, duplicate exclusion, immutable prior checkpoints and persistent STOP; automatic cross-turn native continuation remains pending its first observed boundary. No claim of a tested external Codex supervisor is made.
